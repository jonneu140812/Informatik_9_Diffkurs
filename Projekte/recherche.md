# Leitfrage 

Sollte man einen Passwort Manager nutzen und wenn ja welchen? 

#  Dienste
- https://proton.me/pass (8.10)
- https://1password.com/ (8.10)
- keepassxc.org (8.10)

## Überblick

### Proton
- kostenlose version
- Hat zero-knowledge, laut sich selbst
- besitzt Sync functionalität

### 1Passwort
- kostenlose version
- Hat zero-knowledge, laut sich selbst
- besitzt Sync functionalität

### KeepassXC
- Kostenlos, keine bazahlte version
- Zero-Knowledge, weil es ist lokal
- fehlende Sync functionalität, weil passworter nur lokal sind

# Kriterien

- Kostenlose Option + Eine Anzahl an Features bei dieser
- Zero-Knowledge structure
- Automatiosche Sync funktionalität

# Auswahl

Von den Dreien entschiedete ich, mich für Proton pass, weil er
1. eine kostenlose version hat (https://proton.me/pass, 8.10)
2. laut sich selbst Zero-knowledge (https://proton.me/pass, 8.10), aber noch keine information zu Zero-knowledge von anderen zu diesem punkt gefunden
3. hat Automatiosche Sync funktionalität (https://proton.me/pass, 8.10)
